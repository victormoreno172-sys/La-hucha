# La Hucha

App para organizar el dinero mes a mes: lo que cobras, lo que gastas cada día, lo que quieres ahorrar y cuánto puedes gastar hoy.

- **Descargar para Android:** https://github.com/victormoreno172-sys/la-hucha/releases/download/app/LaHucha.apk
- **Versión web:** https://victormoreno172-sys.github.io/la-hucha/

Los datos se guardan solo en el móvil. En Ajustes → Copia de seguridad puedes copiarlos y restaurarlos.

## Cómo se actualiza

Cada cambio en `index.html` o en `app/` compila solo un APK nuevo (pestaña Actions). Se instala encima del anterior sin perder datos.
